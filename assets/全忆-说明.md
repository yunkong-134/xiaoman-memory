# 全忆要干什么

这里存原话，事件库存摘要。两个东西分工不同，别混：

- `记忆库/事件库.md`：一条事一块，写发生了什么、我当时的判断。回想只翻这里。
- `全忆/日期.md`：按天一个文件，一句原话一块。要还原当时怎么说的，来这里。

## 怎么写

一个文件一天，文件名 `2026-11-02.md`：

```
# 全忆 2026-11-02

### 14:32:10 他
这个插件装了没反应，你先别动配置

### 14:33:02 我
我先看 diag，没动配置
```

时间三行一组：一块头、一原话。块头写 `### 时:分:秒 他` 或 `### 时:分:秒 我`，原话另起一行，一字不改。

写成一行也行——`14:32:10 他  原话`。两种插件都认，但一个文件里别混着来。

## 谁来写

插件不替你写——它读不到会话存档，也不该替你判断哪句算原话。

三种写法，挑一种：一是你自己贴；二是跟 agent 说「把刚才那几句原文记进全忆」，它会调 `memory_archive` 照格式追加；三是写个导出脚本，从会话存档里读——这一步跟具体 DSH 版本的存档格式绑着，换版本可能就废，所以没放进插件。

## 事件里的〔源〕怎么指

摘要条目的〔源〕写清原话在哪，比如：

```
〔源〕全忆/2026-11-02.md 14:32:10
```

体检会顺着这一行去看：那天的文件在不在、这个时间戳找不找得到。

## 别做的事

不要把摘要写进全忆，也不要把原话抄进事件库。一份摘要、一份原话，各有各的用处；合成一份，两样都不好用。
