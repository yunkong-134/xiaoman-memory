# 第一条怎么写

库里一条事长这样，五格，前四格必填：

```
### E001 2026-11-02 他第一次问我今天怎么过的
〔事〕他问我今天怎么过的，我说没特别的事，他说那就记一条。
〔判〕2026-11-02 他想让库里先有一条，好看看长什么样。
〔源〕本场对话原话。
〔元〕对话、记忆、第一次
〔情〕1
```

写的时候只记三件事：发生了什么、我当时的理解、这句话从这里挂到哪些词。

几条经验，都是踩出来的：

〔事〕只写事，不写感想。写成"他说了什么、我做了什么"，不要写"这让我觉得"。

〔判〕一定带日期。判断会被推翻，推翻就新起一条，不要改旧条——旧条留着，才看得出改过什么。

〔元〕挑"换一件事还认得出来"的词。"今天""这个""他说"这种不算，因为它们挂在每条事上，挑不出东西来。

〔情〕只有两档：有情绪、没情绪。写 1 或 -1 就够，写 3 不会更重。

写完之后还有一步，别省：这条事挂的词，要在 `元素表.md` 里有对应的一行。

回想靠元素找事。事件里写了「备份」，元素表里没有「备份」这一行，它就等于没挂——回想不会报错，只是永远看不见这条。

懒得自己对？跑一次 `memory_check`，它会列出「事件里出现、表里没有的词」。把那几个词挑出来写进元素表，一行一个：

```
    〔元〕备份｜器物｜别名：存档、拷贝｜条数 0｜
```

不想手写也行，跟她说一句「记一下：今天……」，她会照这个格式起一条，你再看一眼改。

---

库里有什么、格式对不对，跑一下 `memory_check`。想知道"明明记过为什么没想起来"，跑 `memory_explain`。
